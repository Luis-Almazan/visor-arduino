# Contador de Dedos con Visión Artificial y Comunicación Serial

El proyecto utiliza una cámara web y la librería MediaPipe para detectar en tiempo real cuántos dedos levanta una mano. El número de dedos se muestra en pantalla y se envía por puerto serial a un Arduino, permitiendo activar dispositivos externos según el conteo. Se implementa lógica para mejorar la precisión, evitando lecturas inestables y mostrando la información con OpenCV.
